This project adapts the official ModernTCN implementation:
https://github.com/luodhhh/ModernTCN

ModernTCN paper: Donghao Luo and Xue Wang, "ModernTCN: A Modern Pure Convolution Structure for General Time Series Analysis," ICLR 2024.

The original ModernTCN copyright notice and MIT license are retained in `LICENSE`. The code in this repository adds FAFW-Conv-specific fractional filtering, wavelet processing, task heads, and experiment scripts. See the manuscript for the distinction between the historical model configuration and the audited implementation in this repository.
